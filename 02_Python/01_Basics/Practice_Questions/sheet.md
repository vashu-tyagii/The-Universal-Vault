# Python Basics Practice — Vashu Tyagi

Rule: Solve without AI, without looking up syntax. If you get stuck, write down 
exactly where — that's your real gap, not "Python is hard."

Do these in order. One section → check yourself → then move to the next.

---

## 1. Variables & Data Types

1. Create variables for your name (string), age (int), height in meters (float), 
   and whether you're a student (boolean). Print all of them.
2. Check and print the type of each variable using `type()`.
3. Convert a string "25" into an integer and add 5 to it. Print the result.
4. Create two variables `a = 10` and `b = 3`. Print the result of a/b, a//b, and a%b — 
   explain in a comment what the difference is between / and //.

---

## 2. Input and Output

1. Take a user's name as input and print "Hello, [name]!"
2. Take two numbers as input (as strings by default) and print their sum 
   (remember to convert to int/float first).
3. Take a user's age as input and print whether they'll be eligible to vote 
   this year (age >= 18).

---

## 3. Conditional Statements

1. Write a program that takes a number and prints "Positive", "Negative", or "Zero".
2. Write a program that takes a student's marks (0-100) and prints their grade:
   90+ = A, 75-89 = B, 60-74 = C, below 60 = F.
3. Write a program that checks if a number is even or odd.
4. Take three numbers as input and print the largest one (using if-elif-else).

---

## 4. Loops

1. Print numbers from 1 to 20 using a `for` loop.
2. Print only the even numbers from 1 to 50.
3. Calculate the sum of numbers from 1 to 100 using a loop.
4. Print the multiplication table of 7 (7x1 to 7x10).
5. Using a `while` loop, keep asking the user for a number until they enter 0.
6. Print a pattern of stars — 5 rows, where row 1 has 1 star, row 2 has 2 stars, and so on.

---

## 5. Lists

1. Create a list of 5 course names (e.g., "SQL", "Python", "Power BI", etc.). 
   Print the first and last item.
2. Add a new course to the end of the list, then remove one specific course.
3. Sort a list of numbers `[45, 12, 89, 3, 67]` in ascending and then descending order.
4. Find the sum, max, and min of a list of numbers without using built-in sum()/max()/min() — 
   write it with a loop.
5. Reverse a list without using the built-in `.reverse()` method.
6. Given a list of numbers, create a new list containing only the even numbers 
   (use a for loop first, then try it again using list comprehension).

---

## 6. Tuples

1. Create a tuple with your name, age, and city. Try to change one value — 
   observe and note the error you get.
2. Unpack a tuple `(10, 20, 30)` into three separate variables.
3. Find the index of a specific item inside a tuple.
4. Convert a list into a tuple, and a tuple into a list.

---

## 7. Dictionaries

1. Create a dictionary for a student with keys: name, course, fees. Print each value.
2. Add a new key-value pair to the dictionary (e.g., "placement_status").
3. Loop through the dictionary and print all keys, then all values, then both together.
4. Check if a specific key exists in the dictionary before trying to access it.
5. Create a dictionary of 5 students with their marks, then find the student 
   with the highest marks.

---

## 8. Sets

1. Create a set of 5 numbers, including some duplicates — observe that duplicates disappear.
2. Add an item to a set, and remove an item from a set.
3. Create two sets and find their union, intersection, and difference.
4. Convert a list with duplicate values into a set to remove duplicates, 
   then convert it back to a list.
